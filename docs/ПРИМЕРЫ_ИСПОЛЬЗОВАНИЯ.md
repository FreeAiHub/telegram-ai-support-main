# 📚 Примеры использования Telegram AI Bot

## 🎯 Базовое использование

### 1. Простой вопрос-ответ

**Пользователь:**
```
Привет! Как работает квантовый компьютер?
```

**Бот:**
Ответит с использованием модели по умолчанию (GPT-3.5-turbo)

---

### 2. Смена модели для сложных задач

**Для сложного вопроса:**
```
/model anthropic/claude-3.5-sonnet
```

**Затем задайте вопрос:**
```
Объясни квантовую запутанность с примерами из реальной жизни
```

---

### 3. Использование быстрых моделей

**Для быстрых ответов:**
```
/model google/gemini-2.0-flash-exp
Какая погода в Москве?
```

---

## ⚙️ Настройки для разных задач

### 1. Проверка текущей модели

```
/info
```

Нажмите "Модель" чтобы увидеть текущую и выбрать другую.

---

### 2. Сброс контекста

**Когда хотите начать новую тему:**
```
/reset
```

**Или с новым промптом:**
```
/reset Ты эксперт по маркетингу
```

---

### 3. Настройка предпочтений

```
/info → Preferences
```

Включите/выключите:
- История диалога
- Предложения вопросов
- Название модели в ответах
- Разбивка длинных текстов

---

## 💡 Полезные советы

### Для экономии средств:
1. Используйте GPT-3.5-turbo для простых вопросов
2. GPT-4o / Claude только для сложных задач
3. Gemini Flash для быстрых ответов

### Для лучших результатов:
1. Будьте конкретны в вопросах
2. Предоставляйте контекст
3. Используйте подходящую модель для задачи
4. Включайте историю для связанных вопросов

### Для работы с документами:
1. Включите историю перед загрузкой (`/info` → Chat history)
2. Загрузите документ
3. Задавайте конкретные вопросы
