# Инструкция по запуску Telegram AI Support Bot

## Описание

Этот бот предоставляет AI-поддержку в Telegram с следующими возможностями:
- ✅ Ответы на вопросы с помощью AI (OpenAI GPT)
- ✅ Веб-поиск (DuckDuckGo по умолчанию, опционально Google)
- ✅ Сканирование и анализ документов (PDF, TXT, MD, Python)
- ✅ Анализ изображений
- ✅ Обработка URL и веб-страниц
- ✅ Русский интерфейс

## Требования

- Python 3.11 или выше (установлена версия: 3.13.7 ✅)
- OpenAI API ключ (или совместимый API)
- Telegram Bot Token (уже настроен)

## Настройка

### 1. Получение API ключей

#### OpenAI API Key
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте его в файл `.env` (параметр `API`)

#### Альтернативные провайдеры (опционально)
Вы можете использовать совместимые API:
- [OpenRouter](https://openrouter.ai) - доступ к разным моделям
- [Together AI](https://together.ai)
- [Groq](https://groq.com) - быстрые модели

### 2. Редактирование конфигурации

Откройте файл `.env` и замените `YOUR_OPENAI_API_KEY_HERE` на ваш реальный API ключ:

```bash
API=sk-your-actual-api-key-here
```

### 3. Опциональные настройки

#### Google Search (опционально)
Для использования Google вместо DuckDuckGo:
1. Получите API ключ: [Google Cloud Console](https://console.cloud.google.com)
2. Создайте Custom Search Engine: [CSE](https://programmablesearchengine.google.com)
3. Добавьте в `.env`:
```bash
GOOGLE_API_KEY=your_google_api_key
GOOGLE_CSE_ID=your_cse_id
```

#### Whitelist пользователей (опционально)
Ограничить доступ к боту:
```bash
whitelist=123456789,987654321  # ID пользователей через запятую
```

Узнать ID пользователя: используйте [@userinfobot](https://t.me/userinfobot)

#### Админ-список (опционально)
Только админы смогут изменять настройки бота через команду `/info`:
```bash
ADMIN_LIST=123456789
```

## Использование бота

### Основные команды

- `/start` - Начать работу с ботом и посмотреть инструкции
- `/info` - Просмотр/изменение настроек, модели, языка
- `/reset` - Очистить историю диалога
- `/model gpt-4` - Быстрая смена модели

### Возможности

1. **Обычный чат**: Просто напишите сообщение боту
2. **Загрузка документов**: Отправьте PDF/TXT/MD файл для анализа
3. **Анализ изображений**: Отправьте изображение с вопросом
4. **Веб-поиск**: Бот автоматически ищет в интернете при необходимости
5. **Обработка URL**: Отправьте ссылку для анализа содержимого

### Групповые чаты

Чтобы добавить бота в группу:
1. Пригласите бота в группу
2. Сделайте бота администратором ИЛИ
3. Отключите Privacy Mode в [@BotFather](https://t.me/BotFather):
   - Отправьте `/mybots` → выберите вашего бота
   - Bot Settings → Group Privacy → Turn off

## Полезные настройки бота

Все эти параметры можно изменить в файле `.env`:

```bash
# История диалога (количество сообщений)
PASS_HISTORY=10

# Автоматическая склейка длинных сообщений
LONG_TEXT=True

# Анализ изображений
IMAGEQA=True

# Разбивка длинных ответов
LONG_TEXT_SPLIT=True

# Предложения следующих вопросов
FOLLOW_UP=False

# Показывать название модели в ответах
TITLE=False
```

## Устранение проблем

### Бот не отвечает
- Проверьте, что API ключ правильный
- Проверьте интернет-соединение
- Посмотрите логи в терминале

### Ошибка "Timeout"
- Перезапустите бота
- Проверьте доступность Telegram API в вашем регионе

### Бот не работает в группе
- Убедитесь, что Privacy Mode отключен
- Или сделайте бота администратором
- Проверьте GROUP_LIST (если настроен)
