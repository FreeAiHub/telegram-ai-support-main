
### 2️⃣ Найдите бота в Telegram

Откройте: [@Assistants_PTbot](https://t.me/Assistants_PTbot)

### 3️⃣ Начните диалог

```

```

## ⚡ Быстрые команды

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу |
| `/info` | Настройки и выбор модели |
| `/model openai/gpt-4o` | Переключить модель |
| `/reset` | Очистить историю |

## 🎯 Доступные модели

### Рекомендуемые для начала:

**Для обычных задач:**
```
/model openai/gpt-3.5-turbo
```

**Для сложных задач:**
```
/model anthropic/claude-3.5-sonnet
```

**Для быстрых ответов:**
```
/model google/gemini-2.0-flash-exp
```

**Топовая модель:**
```
/model openai/gpt-4o
```
