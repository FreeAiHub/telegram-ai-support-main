# ⚡ Автономная работа бота 24/7

## Проблема

Когда вы запускаете бота командой `python3 bot.py`, он работает **только пока включен компьютер** и открыт терминал. Если закрыть терминал или выключить компьютер — бот остановится.

## Решение: Облачный хостинг

Для **круглосуточной работы без включенного ПК** нужно развернуть бота на облачном сервере.

---

## 🚀 Варианты размещения

**Преимущества:**
- ✅ Бесплатный tier навсегда
- ✅ Автоматическое развертывание
- ✅ Автомасштабирование
- ✅ Бот спит когда неактивен (экономия ресурсов)
- ✅ Один клик для деплоя

**Настройка:**

1. **Зарегистрируйтесь:** https://app.koyeb.com

2. **Нажмите кнопку деплоя:**

   [![Deploy to Koyeb](https://www.koyeb.com/static/images/deploy/button.svg)](https://app.koyeb.com/deploy?name=ai-assistant&type=docker&image=docker.io/yym68686/chatgpt:latest&instance_type=free&regions=was&instances_min=0&autoscaling_sleep_idle_delay=300)

3. **Заполните переменные окружения:**

```bash
BOT_TOKEN=ВАШ_ТОКЕН_ИЗ_BOTFATHER
API=ВАШ_КЛЮЧ_OPENROUTER
BASE_URL=https://openrouter.ai/api/v1
MODEL=amazon/nova-2-lite-v1:free
CUSTOM_MODELS=-all;Free:amazon/nova-2-lite-v1:free,tngtech/tng-r1t-chimera:free,z-ai/glm-4.5-air:free,kwaipilot/kat-coder-pro:free

get_url_content=True
download_read_arxiv_pdf=True
SYSTEMPROMPT=You are a professional personal AI assistant. You help with information search, document analysis, and answering questions. Always respond in the same language as the user's question (Russian, Portuguese, English, Chinese, etc.). Be concise, helpful, and professional. You have internet access and can analyze documents.
WEB_HOOK=https://your-koyeb-app-name.koyeb.app/
```

4. **Нажмите Deploy**

✅ **Готово!** Бот работает 24/7 автономно.

### 3. **Fly.io**

**Преимущества:**
- ✅ Надежность
- ✅ Глобальное распределение
- ✅ Хорошая документация

**Настройка:**

1. **Установите Fly CLI:**
   ```bash
   brew install flyctl  # macOS
   # или
   curl -L https://fly.io/install.sh | sh
   ```

2. **Авторизуйтесь:**
   ```bash
   flyctl auth login
   ```

3. **Запустите деплой:**
   ```bash
   cd /Users/investing/GitHub/Support_agent/telegram-ai-support
   flyctl launch --image yym68686/chatgpt:latest
   ```

4. **Установите секреты:**
   ```bash
   flyctl secrets set BOT_TOKEN=ВАШ_ТОКЕН_ИЗ_BOTFATHER
   flyctl secrets set API=ВАШ_КЛЮЧ_OPENROUTER
   flyctl secrets set BASE_URL=https://openrouter.ai/api/v1
   flyctl secrets set MODEL=amazon/nova-2-lite-v1:free
   flyctl secrets set LANGUAGE=English
   flyctl secrets set get_search_results=True
   flyctl secrets set get_url_content=True
   flyctl secrets set download_read_arxiv_pdf=True
   flyctl secrets set CUSTOM_MODELS="-all;Free:amazon/nova-2-lite-v1:free,tngtech/tng-r1t-chimera:free,z-ai/glm-4.5-air:free,kwaipilot/kat-coder-pro:free"
   flyctl secrets set SYSTEMPROMPT="You are a professional personal AI assistant. You help with information search, document analysis, and answering questions. Always respond in the same language as the user's question. Be concise, helpful, and professional."
   ```

**Стоимость:** От $5/месяц

### 5. **VPS (Самостоятельный сервер)**

**Для профессионалов:**

**Провайдеры:**
- **DigitalOcean** - от $4/месяц
- **Hetzner** - от €4/месяц
- **Linode** - от $5/месяц
- **AWS EC2 / Google Cloud** - бесплатный tier 12 месяцев

**Настройка на Ubuntu:**

```bash
# 1. Установка зависимостей
sudo apt update
sudo apt install python3 python3-pip git -y

# 2. Клонирование репозитория
git clone https://github.com/yym68686/ChatGPT-Telegram-Bot.git
cd ChatGPT-Telegram-Bot
git submodule update --init --recursive

# 3. Установка Python зависимостей
pip3 install -r pyproject.toml

# 4. Создание .env файла
cat > .env << 'EOF'
BOT_TOKEN=ВАШ_ТОКЕН_ИЗ_BOTFATHER
API=ВАШ_КЛЮЧ_OPENROUTER
BASE_URL=https://openrouter.ai/api/v1
MODEL=amazon/nova-2-lite-v1:free
CUSTOM_MODELS=-all;Free:amazon/nova-2-lite-v1:free,tngtech/tng-r1t-chimera:free,z-ai/glm-4.5-air:free,kwaipilot/kat-coder-pro:free
LANGUAGE=English
get_search_results=True
get_url_content=True
download_read_arxiv_pdf=True
SYSTEMPROMPT=You are a professional personal AI assistant. You help with information search, document analysis, and answering questions. Always respond in the same language as the user's question. Be concise, helpful, and professional.
EOF

# 5. Создание systemd сервиса (автозапуск)
sudo cat > /etc/systemd/system/telegram-bot.service << 'EOF'
[Unit]
Description=Telegram AI Assistant Bot
After=network.target

[Service]
Type=simple
User=YOUR_USERNAME
WorkingDirectory=/home/YOUR_USERNAME/ChatGPT-Telegram-Bot
ExecStart=/usr/bin/python3 /home/YOUR_USERNAME/ChatGPT-Telegram-Bot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 6. Запуск сервиса
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot

# 7. Проверка статуса
sudo systemctl status telegram-bot
```

**Просмотр логов:**
```bash
sudo journalctl -u telegram-bot -f
```

## 🔧 Устранение проблем

### Бот не отвечает

1. **Проверьте логи** в панели управления платформы
2. **Проверьте переменные окружения** - все ли установлены
3. **Проверьте баланс OpenRouter**

### Бот падает

1. **Проверьте логи** на ошибки
2. **Убедитесь** что `CUSTOM_MODELS` установлен правильно
3. **Перезапустите** сервис
