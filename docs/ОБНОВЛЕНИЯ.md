# 🎉 Последние обновления бота

## ✅ Что изменено (14.12.2025)

### 1. **Только бесплатные модели** 💰
Бот теперь использует **только бесплатные модели** через OpenRouter:
- `amazon/nova-2-lite-v1:free` (по умолчанию)
- `tngtech/tng-r1t-chimera:free`
- `z-ai/glm-4.5-air:free`
- `kwaipilot/kat-coder-pro:free`

**Преимущества:**
- ✅ Никаких расходов для пользователей
- ✅ Ваш API ключ используется для всех
- ✅ Ротация между моделями доступна

### 2. **Убрано требование API ключа** 🔑
- ❌ Больше НЕТ запроса установить API ключ при `/start`
- ✅ Пользователи сразу могут начать работу
- ✅ Простое приветствие с командами

Бот теперь автоматически определяет язык запроса и отвечает на нём:

**Поддерживаемые языки:**

- 🇺🇸 **Английский** - Write in English, get response in English

**Как работает:**
```

Usuário: Olá! Como você está?
```

## 🚀 Как использовать

### 1. Запуск диалога

Просто напишите боту на любом языке:

**Русский:**
```
Привет! Расскажи о квантовых компьютерах
```

**Português:**
```
Olá! Me fale sobre computadores quânticos
```

**English:**
```
Hello! Tell me about quantum computers
```

### 2. Смена модели

Все модели бесплатные, можете переключаться:

```
/model tngtech/tng-r1t-chimera:free
/model z-ai/glm-4.5-air:free
/model kwaipilot/kat-coder-pro:free
```

Или через меню:
```
/info → выберите модель
```

### 3. Просмотр доступных моделей

```
/info
```

Нажмите "Change model" и увидите группу **Free** с 4 бесплатными моделями.

## ⚙️ Техническая информация

### Конфигурация (.env)

```bash
# Модель по умолчанию
MODEL=amazon/nova-2-lite-v1:free

# Только бесплатные модели
CUSTOM_MODELS=-all;Free:amazon/nova-2-lite-v1:free,tngtech/tng-r1t-chimera:free,z-ai/glm-4.5-air:free,kwaipilot/kat-coder-pro:free

# Системный промпт для автоопределения языка
SYSTEMPROMPT=You are a helpful AI assistant. Always respond in the same language as the user's question. If the user writes in Portuguese, respond in Portuguese. If in Russian, respond in Russian. If in English, respond in English. Auto-detect and match the user's language.

# Язык интерфейса (кнопки, меню)
LANGUAGE=English
```

### Доступные языки в интерфейсе

Через `/info` → Language можно выбрать:
- 🇺🇸 English
- 🇨🇳 Simplified Chinese
- 🇭🇰 Traditional Chinese
- 🇷🇺 Russian
- 🇵🇹 Portuguese (добавлен)
